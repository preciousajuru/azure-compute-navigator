Decision principles A few distinctions that change the answer

Compute and databases are separate decisions. Engine compatibility and network paths do not select an app host.

AI is an application pattern. Calling a managed model API does not mean you host a model.

More control brings more work. Choose Kubernetes or VMs only when their capabilities are requirements.
